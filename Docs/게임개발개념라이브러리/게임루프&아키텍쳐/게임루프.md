# 게임루프
    -입력이 있든 없든 스스로 계속 도는 반복문.
    -게임은 기다려 주지 않는다.


## 무엇을
    - 게임 루프를 입력, 갱신, 렌더링을 프레임(한 바퀴)으로 표현한 것이다.

    - 입력은 이벤트로 만들어줘
    - 갱신은 delta time으로 표현하도록 구성해라
    - 화면을 그려줘

## 무슨 문제가 발생했나요?
    - 플레이어가 벽으로 이동하면 벽이 오른쪽으로 치우친다.
    

## 왜
    콘솔 특성상 가로와 세로의 크기가 다르다.

## 실습
    - 게임 루프, 용어들을 총 동원해서 게임을 만들어야 한다.
    - 똥피하기, 스네이크 게임등 실시간으로 움직이고 wasd로 조작할 수 있는 게임
