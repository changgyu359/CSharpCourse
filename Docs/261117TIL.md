# 깃을 통한 프로젝트 관리

- 수업 내용 정리.
    1>깃과 깃허브
    깃은 원격 저장소에 프로그램을 저장하는 프로그램이다.
    깃허브는 깃의 기능에 더해 내가 저장한 프로그램을 다른 사람들과 쉽게 공유할 수 있게 해주는 프로그램이다.
    2>깃을 올리는 과정
    깃을 올리려면 먼저 레파지토리를 생성해야 한다. 레파지토리를 생성한 후 내가 올릴 파일을 커밋해야한다.
    커밋을 했다면 마지막으로 커밋한 파일을 푸쉬해서 파일을 리모트에 저장할 수 있다.
    3>로컬과 리모트 / 이 사이에 파일의 흐름을 이해했는가
    로컬은 내가 구동중인 환경, 리모트는 원격 저장소
    로컬에서는 내가 파일을 제작하고 저장하여 리모트로 올릴 수 있다. 리모트에 올라간 파일은 이후 로컬에서 풀을받아 이어할 수 있게된다.

[육하원칙]
- 누가 깃을 쓰는가?
    컴퓨터 언어를 사용하는 프로그램을 제작하는 모두
- 왜 쓰는가?
    1.파일을 로컬이 아닌 다른곳에 저장하기 위해
    2.파일을 다른사람들과 쉽게 공유하기 위해
- 언제 쓰면 좋을까?
    1.실제 거리가 먼 로컬 환경에서 파일을 옮겨야 할 때
    2.여럿이서 하나의 프로젝트를 공동으로 진행할 때
- 어디에서 활용하고 되고 있을까?
    1.컴퓨터 언어를 배우는 학원
    2.대형 게임을 제작하는 게임회사
    3.프로그램을 배포하는 개인 개발자의 배포처
